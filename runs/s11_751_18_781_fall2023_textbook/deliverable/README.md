# Deliverable Exports

This directory is reserved for final user-facing outputs only.

## Expected layout

- `lectures/<lecture_slug>/lecture_XX_note.tex`
- `lectures/<lecture_slug>/lecture_XX_note.pdf`
- `book/<merged_textbook>.tex`
- `book/<merged_textbook>.pdf`

## Export rules

- Export here only after evaluator and validator gates pass.
- Copy deliverable artifacts here; do not remove the canonical files from `lectures/` or `build/`.
- Do not place intermediate sidecars, raw assets, or debug logs here unless they are explicitly part of the final user-facing package.
- If a requested final lecture note or merged textbook is missing here, the work is not finished yet.
