Motion planning for robots

• Usually we assume the geometry of the
  environment is fully known.
• We want to find a path from the START
  position to the GOAL position while avoiding
  collision with obstacles.
• Solved by research in the 1980s and 1990s.
  Sampling based methods proved practical.

Represent the free configuration
 Cfree space by a 1D roadmap R

 Separately find paths from START to R and GOAL to R,
 and link them via a path on R

Next We need to go from paths to trajectories
