           Lecture 12A: Long Horizon Planning and the Role of Language
                                                     Abstract
          The lecture discusses how humans do long-horizon planning in steps and its implications for robotics
       and AI. It highlights that human behaviors are hierarchical, with actions comprising both physical
       movements and goal-oriented purposes, showing the importance of the roles of both high-level abstract
       reasoning and low-level physical understanding. The lecture further covers the evolution of planning
       approaches in robotics, from early systems like SHAKEY to modern language models, while also discussing
       their limitations.


21.1      Introduction
Human behavior is hierarchical and has many levels – movements, goals, actions, and events (Barker and
Wright, 1954). All human activities and tasks can be constructed by these hierarchies. For robots, they have
to be the same.
There is an important concept to understand the behaviors: ACTION = MOVEMENT + GOAL. For
every action, there is a movement space that is governed by the laws of physics, and a space of goals that
represents the purpose behind the movement. These two identities are equally important to study
robotics. Consider comparing Harry Potter as a book versus a movie: the physical movements are more
apparent in the movie, while the characters’ goals and intentions are clearer through the book’s language.
Studying robotics requires both these aspects. The claim that “LLMs can do everything” overlooks this
distinction – while language models are good at capturing abstract goals, they are not necessarily good at
capturing the movement.

21.2      Long Horizon Planning
In this section, we discuss approaches that are used for long-horizon planning to solve these hierarchical tasks.

21.3      SHAKEY
SHAKEY (Nilsson, 1984), shown in Figure 88, is one of the earliest examples of planning in the field of
robotics. To solve the planning problem, they designed logical operators as actions. For example, if the goal
is to stack block cubes, the operators can be actions that the robot can take, like “pick up” or “put down”.
Each operator consists of:

  1. Pre-condition lists: The initial conditions that are required to execute an operator. For example, the
     "pick up" operator can only be executed if the robot is near the object and has an unobstructed path.

  2. Delete lists: The facts that are no longer true after the operator has been executed. For example,
     after the “pick up” operator is executed, the fact that the object is on the table would be added to the
     delete list.

  3. Add lists: The facts that become true after an operator has been executed. For example, after the
     “pick up” operator is executed, the fact that the robot is holding the object is added to the add list.

These components are all defined using logic, and, given a goal state, the planning involves determining the
sequence of operators needed to transition from the initial state to the desired end state.

21.4    Planning Domain Definition Language (PDDL)
PDDL is a formalism used to describe domains, along with plans and goals for within them McDermott
(2000). The domain is specified through:

  1. A set of object types

  2. Predicates describing properties and relationships across objects.

  3. Actions which may be taken by the agent in the environment. Actions are represented by parameters
     (the objects involved), preconditions (predicates which must be true for the action to be possible to
     take), and effects (resulting changes to environment from the action).

States in the domain are represented by a set of objects and a set of predicates which are currently true.
Problems are specified for planning by providing an initial state and a goal state.




        Figure 89: An example “Logistics" domain specified in PDDL. Source: McDermott (2000)

It is important to note that PDDL is an abstract formalism used for symbolic planning, and does not
fundamentally consider how to physically execute actions in its plans.

21.5    Task And Motion Planning (TAMP)
In contrast to PDDL, TAMP (Lozano-Pérez and Wesley, 1979; Garrett et al., 2021), combines high-level
symbolic planning with low-level motion planning, such that an agent can plan desired actions to take in the
world in tandem with how to physically execute them.
Generally speaking, the high-level planner can be used to set motion goals and constraints for the low-level
motion planner to follow when executing an action.




Figure 90: An example of a TAMP kinematic tree. Notice how this representation considers not just the
objects and physical relationships across them, but also the physical configuration of the robot relevant for
movement in the environment. Source: Garrett et al. (2021)

The motion planning component assumes full knowledge of the world, and is primarily concerned with
satisfying the constraints of motion, such as collision avoidance.

21.6    Language Models and Operators
One of the main challenges stemming from classical approaches to motion planning stem from the necessity
to fully specify the set of predicates and operators used to describe a domain. Large language models (LLMs)
contain implicit common-sense knowledge about the world, and therefore may serve as useful tools for inferring
predicates and operators, freeing the roboticist from having to manually and exhaustively specifying them.
While modern LLMs still struggle with generating logically coherent plans, approaches using program synthesis
show promise in this direction (Singh et al., 2023).

21.7    What is Language Not Good For?
21.8    Spatial Cognition
Some prior work has argued that because of the common-sense knowledge that LLMs implicitly acquire, they
may be capable of being applied to multimodal tasks – in other words, that “if you train a word model, you
will get a world model for free."
Recent work has shown, however, that LLMs and vision-language models (VLMs) struggle with spatial
reasoning (Ramakrishnan et al., 2024; Kamath et al., 2023).
Consider the spatial reasoning benchmark from Ramakrishnan et al. (2024) (Figure 91). This paper defines
a suite of spatial reasoning evaluations (e.g. mental rotation, shape matching, line orientation judgments,
etc.) and tests a set of modern VLMs on it, finding that all models perform below human performance (gray
numbers in the figure).

21.9    Precisely Specifying Low-level Movements
Consider the task of learning how to climb a staircase. A language description of such an endeavor would
likely require high-verbosity and specificity (e.g. see the description provided by Julio Cortazar: (Cortázar,
1969)). Sequences of low-level movements like these do not lend themselves towards being efficiently described
in language, and describing them using the motion itself (or video) for imitation provides a much more
efficient mode of transmission.

21.10     Conclusion
In this lecture we considered the role of language in robotics, emphasizing its usefulness as a signal for com-
municating high-level abstractions specifying plans, goals, and environment properties. Recent advancements
in LLMs may also provide an avenue for automating the generation of these high-level abstractions for use in
robotics settings. Although language can be greatly useful at these levels of abstraction, it is not an efficient
mode of transmission for communicating fine-grained details of movements and actions.
