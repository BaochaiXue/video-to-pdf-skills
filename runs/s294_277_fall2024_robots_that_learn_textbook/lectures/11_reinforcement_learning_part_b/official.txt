The Usage of Simulators
• Use simulator to develop algorithm -> Run the same algorithm using RL.
• Use simulator to “train” the algorithm -> deploy the model to the real-world.
  • The point is not “sample-efficiency” any more.
  • Sample-efficiency still helps in iteration speed.
