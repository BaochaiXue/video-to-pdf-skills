\chapter{建议阅读路径 Suggested Reading Paths}
\section*{线性课程路径}
第一次系统学习 advanced LLM agents 时，建议按 Chapter 1--12 顺序阅读。这样能先建立统一 vocabulary，再逐步进入 code、multimodality、formal mathematics 与 security。
\section*{Reasoning-first 路径}
若重点是 reasoning、judge、search 与 theorem proving 的共通结构，建议读 Chapter 1, 2, 3, 4, 8, 9, 10, 12。
\section*{Agent systems builder 路径}
若重点是 workflow、tool use、execution-based evaluation 与部署，建议读 Chapter 1, 4, 5, 6, 7, 12。
\section*{Formal methods 路径}
若来自 theorem proving / verification 背景，建议先读 Chapter 8, 9, 10, 11, 12，再回读 Chapter 2 和 Chapter 5。
\section*{安全与安全防护路径}
若最关心 prompt injection、memory poisoning、privilege control 与 trustworthy deployment，建议读 Chapter 1, 5, 7, 11, 12，并配合 Glossary、Notation 与 Omission Log 一起看。
\section*{如何回查 provenance}
每章的 recording、slides、readings、figures 与 evaluator scores 都在 \texttt{textbook\_source\_manifest.json} 和 lecture workspace sidecars 中可追溯。正文遇到术语边界不确定时，优先回查 Glossary、Notation 与 Figure Provenance。
