# Glossary Delta

- discovery agent：能够提出 hypothesis、组织 search、利用反馈并学习 abstraction 的智能体。
- formal representation：把自然语言问题转成 machine-checkable 的 formal statement。
- COPRA：基于 in-context learning 与 proof environment feedback 的 theorem-proving agent。
- symbolic regression：在数据上搜索紧凑可解释公式或程序化假设的任务。
- concept library：由高质量 hypotheses 诱导出的抽象概念库，用来重构后续搜索空间。
- visual concept library：针对视觉任务演化出的概念描述集合。
