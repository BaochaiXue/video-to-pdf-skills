# Glossary Delta

- 推理时计算（inference-time computation）：在部署时为单个任务额外花费的计算预算。
- 链式思维（chain-of-thought, CoT）：显式生成中间推理步骤的解码模式。
- 自洽性（self-consistency）：从多条 reasoning path 中按最终答案聚合。
- 结果级奖励模型（outcome reward model, ORM）：对完整答案整体打分。
- 过程级奖励模型（process reward model, PRM）：对中间步骤逐步打分。
- 自调试（self-debugging）：借助执行反馈、trace 或错误信息修正程序输出。
