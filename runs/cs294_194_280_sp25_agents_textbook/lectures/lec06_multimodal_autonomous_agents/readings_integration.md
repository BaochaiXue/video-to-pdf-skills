# Readings Integration

- `Mind2Web` is used to frame the offline, real-website data setting: it gives the course a baseline notion of what generalist web-agent data looks like before moving to interactive execution-based environments.
- `WebArena` is integrated where the lecture distinguishes realistic/reproducible web environments from static demonstrations and cached trajectories.
- `VisualWebArena` is the canonical reading for the lecture's visually grounded benchmark half: it justifies screenshots, layout cues, and SoM-style representations.
- `Tree Search for Language Model Agents` is integrated into the inference-time search section, especially for value-guided expansion, search budget scaling, and the dependence on value-function quality.
