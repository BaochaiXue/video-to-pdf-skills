# Glossary Delta

- computer-use agent: 在真实操作系统或多 app 环境中执行任务的 multimodal agent。
- execution-based evaluation: 通过环境状态和脚本检查任务是否完成，而不是比对单一文本答案。
- guided replay: 从教程文本或轨迹中恢复、合成 agent interaction data 的方法。
- CoTA (Chains-of-Thought-and-Action): 同时包含 reasoning trace 与 action trace 的训练数据形式。
- inner monologue: 部署前或部署时显式生成的中间 reasoning，用来改善高层 planning 和低层 grounding。
- temporal encoder: 把长视频压缩成少量 token 的时序抽象模块。
