# L07 Multimodal Agents: From Perception to Action

本讲的核心不是简单介绍几个 benchmark，而是把 multimodal agents 的执行链条拆清楚：环境必须可交互、任务必须可验证、数据必须可扩展、模型必须能在视觉 observation 上完成 grounding、planning 和 action generation。OSWorld 给出 computer-use benchmark；AgentTrek 和 CoTA/TACO 讨论训练数据；AGUVIS 给出 pure-vision GUI policy；xGen-MM-Vid 与 GenS 则把长视频 memory/grounding 纳入 agent design。
