# Lecture Summary

本讲把“从 perception 到 action”拆成三层。第一层是 benchmark realism：OSWorld 说明 computer-use agents 需要真实 environment、task config 与 execution-based evaluation。第二层是 data and training：AgentTrek 与 CoTA/TACO 展示如何从教程、合成 traces 和 thought-action data 中扩展训练分布。第三层是 model design：AGUVIS 强调 pure-vision GUI agents 与 inner monologue，xGen-MM-Vid 和 GenS 则把 long-video memory/grounding 纳入 multimodal agent 范畴。

最重要的结论是，真正的 multimodal agents 不只是“多看一点图像”，而是要把 benchmark、grounding、reasoning、action space 和 memory 一起设计。
