# Lecture 10 Notes

本讲围绕 theorem proving agent 的四个层次展开：

1. informal-formal gap 与 theorem proving 的课程定位。
2. Lean-STaR：在 tactic 之前显式生成 thought，并用 expert iteration 自训练。
3. Draft, Sketch, Prove：用 informal sketch 缩小 formal search space。
4. LeanHammer 与 miniCTX：前者强化低层自动证明，后者把 benchmark 推向真实项目长上下文。
5. ImProver 把证明从“找到”扩展到“优化”。
