# Glossary Delta

- informal-formal gap：非形式推理与形式证明代码之间的表达和执行鸿沟。
- thought-augmented proving：在 tactic 之前生成显式 thought 的证明范式。
- sketch-guided proving：用高层 proof sketch 引导低层 formal prover。
- hammer：把 automated theorem prover 接入 proof assistant 的系统。
- premise selection：从大规模 library 中挑选与当前 goal 相关前提的步骤。
- research-level formalization：面向真实数学项目而非竞赛 benchmark 的形式化工作。
