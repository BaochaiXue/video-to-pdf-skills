# Golden Principles

- The workspace is the record system. Handoffs should prefer machine-readable artifacts over conversational summaries.
- Planning comes before prose. A note should not be written before coverage and segment contracts exist.
- Coverage comes before elegance. Missing detail must be logged, not silently dropped.
- Figures must earn their place. Every figure should improve teaching value and carry provenance.
- Evaluators are allowed to fail fluent notes. Passing requires satisfying the rubric, not just sounding polished.
- Repair should be bounded and explicit. Fix what the evaluator asked for and record what changed.
- Validators should encode teaching invariants, not just file existence.
